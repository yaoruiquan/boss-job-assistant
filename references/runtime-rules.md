# 运行强约束

## 合规与账号安全

- 只用于用户本人账号和本人求职行为。
- 不绕过验证码、登录限制、风控提示或访问控制。
- 不做隐藏自动化、反检测或规避平台限制的逻辑。
- 不批量高速浏览、抓取、保存平台职位库。
- 不对同一公司、同一岗位、同一 Boss 重复打招呼。

## 默认人工关口

必须人工处理：

- 登录和二次验证。
- 验证码、风控弹窗、异常拦截页面。
- 发简历前确认。
- 对方提出无法由规则确定的问题。
- 页面结构变化导致按钮或输入框无法高置信定位。

## 速率限制建议

MVP 默认：

- 每日自动打招呼上限：20。
- 单次连续处理上限：10 个岗位。
- 两次打招呼间隔：30-120 秒。
- 每个岗位进入动作前截图或记录 DOM 摘要。

这些限制是产品安全边界，不是规避检测手段。

## 禁止行为

- 自动点击验证码。
- 自动修改简历内容来适配岗位事实。
- 自动承诺入职、薪资、经验或技能。
- 自动发简历给未回复或关键词未命中的 Boss。
- 通过脚本构造网络请求绕过页面操作。

## 失败处理

出现以下情况时停止本轮执行：

- BOSS 页面要求验证身份。
- 页面元素定位失败两次。
- 消息发送结果无法确认。
- 点击 `立即沟通` 后跳首页、跳推荐页，或没有强成功信号。
- 日志无法写入。
- 达到每日或本轮上限。
